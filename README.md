# ПВЗ Под ключ — сайт

Многостраничный сайт сервиса по запуску и управлению пунктами выдачи заказов.

## Страницы

- `index.html` — главная
- `services.html` — услуги (6 направлений)
- `cases.html` — кейсы
- `about.html` — о нас
- `contacts.html` — контакты и форма

## Структура

```
site/
├── index.html
├── services.html
├── cases.html
├── about.html
├── contacts.html
└── assets/
    ├── css/style.css
    └── js/main.js
```

## Запуск локально

Открыть `index.html` двойным щелчком. Интернет не нужен, всё работает офлайн.

## Публикация на GitHub Pages

1. Создайте на GitHub **пустой** репозиторий (без README), например `pvz-site`.
2. В этой папке (`site`) выполните:

```bash
git init
git add .
git commit -m "initial"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/pvz-site.git
git push -u origin main
```

3. На GitHub откройте репозиторий → **Settings → Pages**.
4. В блоке «Build and deployment» выберите источник **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите Save.
5. Через 1–2 минуты сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/pvz-site/
```

## Свой домен

Да, можно подключить. Для этого:

1. Купите домен у любого регистратора.
2. В DNS-панели регистратора добавьте запись:
   - тип **CNAME**, имя `www`, значение `ВАШ_ЛОГИН.github.io`
   - (для голого домена без `www` — тип **A**, значения `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`)
3. На GitHub: **Settings → Pages → Custom domain**, введите домен и сохраните.
4. Поставьте галочку **Enforce HTTPS**.

Сайт построен на относительных путях, поэтому корректно работает и в подпапке `/pvz-site/`, и на собственном домене в корне.
